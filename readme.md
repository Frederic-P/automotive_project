# CARMAgeDDoN:  END to END deep learning image classification project. 
Car Analysis and Recognition via Machine-learning for Automotive Disambiguation with Deeplearning Networks

CARMAgeDDoN is a project that explored a few different approaches to start from a unclean scraped dataset  and make a model that could predict a brand of a car. It explored a cleaning strategy, compared three CNN strategies and compared against a ViT model.

## SYSTEM
Code was developped for Ubuntu 24.0.4LTS with default AMD drivers for an RDNA2-GPU (Radeon RX6700XT). Workarounds where required to get the GPU registered and working with the code.
