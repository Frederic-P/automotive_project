# Angle tagging: training and application. 

This manual describes the full process used to create and assess a model that tags the angle of a photo into one of eight possible values. The work is split over two notebooks which must be run in sequence due to their interdependencies. First training must be done using: `notebooks/machine learning notebooks/2 - Angle classifier.ipynb`, then the best approach from there is selected and applied to the dataset using `notebooks/model appliers/2 - apply_angletag.ipynb`. 

Only start this phase once you have manually tagged a few thousand images (FlaskTagging.md); try to get about 400 images per angle, the more the better and after you have generated all bounding boxes for your images; it doesn't matter if binary taggin has been applied to the full dataset already (all images will receive an angle tag anyway AND a certainty score). 

The aim of this phase is to subdivide the data to train the brand recognition model on into eight equal sized chuncks of 300.000 images for each of the eight angles; these will be trained in phase 3.x; in the comparison notebook (3.6), the performance will be tested to see if 8 individual models trained on a specific angle are better than one big model trained on all 2.4million images. 

## Training phase: 

This  notebook will augmentate the data untill it has 2500 images for each of the eight target classes. It'll then train two models; one with cropping applied and one without; to crop the data, the Boundingbox values generated by YOLO are used. IT'll then evaluate the performance of the two models using cropped and uncropped data. (again the YOLO boxes are used.)

The comparison is done using a 2 by 2 matrix of confusion matrices and standard error metrics. You essentially get one CM and a bunch of metrics for each of the following approaches: 
- train on cropped image + predict on cropped image
- train on uncropped image + predict on uncropped image
- train on cropped image + predict on uncropped image 
- train on uncropped iamge + predict on cropped image 

The hybrid approaches perform the worst, the best approach was to crop the image in training and during infer. This approach will now be use for the next phases (3 ==> brand prediction. )

Having established cropping the image is the best approach, the data gets retrained on the full set (agumentated where neeeded again) and is saved ready for applying in the next step. 

# Angle tagging: Applying best models. 

This section of the documentation describes the content of `notebooks/model appliers/2 - apply_angletag.ipynb`; it should be run after completing `notebooks/machine learning notebooks/2 - Angle classifier.ipynb`. 

This notebook will connect to the database, fetch all images and process them in batches of 1000 images. The output of this notebook is a new table in MYSQL called `angletag_predicts` with three columns (the image ID (int) model_label (varchar) tagigng the angle as text and model_score (float) how certain the mdoel is). This process can be interrupted at any time, to continue tagging, just relaunch the notebook. 

At the top of this notebook the constant `USE_BBOXES` is declared, this instructs the notebook to infer unseen images using the boundingbox data generated by YOLO. 

After applying a tag to each image the outcomes are explored in the section labeled '2.3 Exploring prediction outcomes'. We see that the model is more confident about tagging an image if it is actually meets the usability criteria set before (i.e. 2 models out of four must rate an image at 0.9 or higher).

The distributions of angles for all brands are made and they are roughly the same across all brands - good. It was briefly considered to further improve the binary classifier by using the angle tagger's certainty score as an ensembel method, though this idea was not pursued; the when you render the final `plot_images_as_grid()` call you hardly get false positives where the car is impossible to identify. We do notice that outcome of angle tagging is not always perfect - that's to be expected as the reported F1 scores are again low 90's.
