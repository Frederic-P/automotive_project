# Binary tagging: training and application. 

This manual describes the full process used to create and apply multilple binary tagging (bintag) models that determines the usability of an image of a car on manually labeled training data generated by the Flask Angle tagger. The work is split across two notebooks which must be run in sequence due to their interdependencies. First training must be done: `notebooks/machine learning notebooks/1 - usability tagger.ipynb`, then the best models from there are selected and applied to the dataset using `notebooks/model appliers/1 - apply_bintag.ipynb`. 

## Training phase: 
Goal is to train and evaluate a bunch of CNN models as binary taggers. The evaluation also looks at how well each model is capable of pulling apart the binary classes as more data is fed into the system (fractionplots)
